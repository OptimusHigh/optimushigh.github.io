Ganj4Craft Launcher & Security

Десктопный клиент с 1-клик входом и античит-защита
В чем польза:

Полная экосистема для сообщества: десктопное приложение на Electron полностью избавляет игроков от ручной установки Java и конфликтов версий. Вход без паролей по одноразовому коду из Telegram, автообновление только измененных файлов по SHA1-хешам. Основной модовый сервер сейчас на переработке, для игроков открыт стабильный ванильный сервер (ganj4craft.ru), бот авторизации обновлен.

Ключевые фичи:

Встроенные резервные зеркала на случай блокировок Mojang. Серверный античит Ganj4Gate проверяет моды игроков криптографическим токеном до входа в мир. Байткод-патчи устраняют фатальные краши графики и утечки памяти.

Тысячи игроков без вылетов. Отказоустойчивая раздача файлов и моментальный вход без паролей. Ванильный сервер онлайн прямо сейчас.

Create: RF Crafter (CreateXMe)

Опубликованный мод энергоэффективной автоматизации
В чем польза:

Решает главную проблему игроков в технологических модах — заменяет гигантские многоблочные лагающие фабрики на один компактный верстак, питающийся стандартной энергией (RF/FE), с прокачкой прямо в мире без сноса блока.
